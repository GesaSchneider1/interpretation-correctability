# Limitations and Claims Discipline

## Limitations

1. One synthetic user and a small number of hand-designed memory cases.
2. Predominantly one open model family and deterministic single-run evaluations.
3. Manual scoring in several experiments with coarse 1 / 0.5 / 0 rubrics.
4. Early experiments contain implementation confounds, including output ceilings, routing errors, and a catastrophic holistic-rewrite failure.
5. Experiment 5 contains one evidence-status metadata deviation.
6. Generic reasoning can sometimes mimic personalization, so behavior alone cannot establish correct memory use.
7. Later protocols were frozen more rigorously than early exploratory experiments; evidential weight is therefore not uniform.
8. No real-user longitudinal deployment, external replication, or statistical prevalence estimate.
9. No tested architecture has solved the full problem.

## Claims that are supported within the tested implementations

Repeated memory updating can distort user-supplied meaning. Memory fidelity and behavioral correctness can diverge. Evidence integrity and interpretation integrity can diverge. Evidence availability does not guarantee correct evidence verification. Temporal currency and contextual scope are meaningful failure dimensions. More skeptical verification can improve corruption detection while destroying valid personalization.

## Claims not established

Structured semantic memory is universally superior. Atomic memory is universally superior to holistic memory. Provenance prevents distortion. Immutable evidence guarantees faithful reconstruction. Evidence grounding guarantees useful personalization. Decomposed verification is superior overall. Interpretation Correctability has been established as a general capability across models or real users.

## Open inference

The sequence suggests that a central challenge for adaptive AI is not simply remembering a person, but calibrating when a machine-generated belief about that person is justified, current, appropriately scoped, and safe to apply. This requires external replication before broader claims are warranted.
